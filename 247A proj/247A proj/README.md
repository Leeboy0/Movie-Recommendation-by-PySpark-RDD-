# movieLens:使用Spark MLlib的ALS算法的电影推荐系统

## 介绍

本仓库提供了一个基于Spark MLlib的ALS算法实现的电影推荐系统。该系统利用了广泛使用的movieLens数据集来展示推荐算法的应用。通过该推荐系统，用户可以获取个性化的电影推荐。

## 数据集

本推荐系统使用的数据集为movieLens数据集，其中包括两个主要的数据文件：ratings.csv和movies.csv。

- **ratings.csv**：该文件包含了用户对电影的评分信息。数据格式为：用户ID，电影ID，评分，时间戳。

- **movies.csv**：该文件包含了电影的基本信息。数据格式为：movieId，标题，类型。

## 结果说明

推荐系统的输出结果格式为：userId，[（电影ID，评分）]。其中，userId表示用户ID，movieId表示电影ID，评分则代表推荐度。
